# DEMONT — Industriedemontage & Rückbau

Interaktive One-Page-Webseite im harten Industrial-Style. Komplett eigenständig:
eine einzige `index.html`, keine Frameworks, keine externen Assets — einfach im
Browser öffnen.

## Features

- **Hero mit WOW-Effekt**: Funken-Partikel-Canvas (folgt der Maus), Slam-Intro
  der Headline, Glitch-Typo, Blaupausen-Raster
- **Abriss-Simulator**: Sprengung mit Countdown, Screen-Shake, kollabierenden
  Gebäuden und Staubwolken — einzelne Etagen auch per Klick abreißbar,
  Wiederaufbau auf Knopfdruck
- **Scroll-Erlebnis**: Warnband-Fortschrittsbalken, Reveal-Animationen,
  animierte Kennzahlen-Zähler, rotierendes Laufband
- **Industrial Design**: Sicherheitsgelb/Schwarz, Hazard-Stripes, Stahl-Grau,
  Körnungs-Overlay, harte Clip-Path-Kanten
- Responsiv und mit `prefers-reduced-motion`-Unterstützung

## Nutzung

```
Öffne index.html im Browser. Fertig.
```
